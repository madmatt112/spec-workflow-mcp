## Context
The SubagentStop hook is the single writer of per-spawn usage. End-to-end scenario 2's live half needs a real session's SubagentStop firing for a supervisor-spawned orchestrator, which requires the checkout rebuilt (npm run build) and the session restarted so agents/skills load at session start and the server reconnects from dist/. At verification time the running session pre-dated the change, so only the tool/script half was exercised in-process (the hook script yields one spawn.end with the six keys for an sdd-*-orchestrator agent; missing transcript gives tokens=unknown). This is design D13's planned deferral.

## Decision Deferred
The live proof that a supervisor-spawned orchestrator's SubagentStop writes a spawn.end row carrying numeric input/output/cacheWrite/cacheRead/tokens and model was not exercised end-to-end in a live session.

## Revisit Criteria
After npm run build and a session restart, run one SDD phase through the supervisor and confirm the orchestrator's spawn.end row in that spec's .spec-workflow/specs/<spec>/harness-events.jsonl carries numeric input, output, cacheWrite, cacheRead, tokens and a model string (not tokens=unknown), with the tokens total equal to the sum of message.usage over that orchestrator transcript's assistant entries.
