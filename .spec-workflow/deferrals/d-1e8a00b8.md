## Context
2026-10-29, tradr run-20261029-040548 (zod-4-and-body-limit): the coordinator answered gate-b w-03a75264 with "Annotate: ..." text. harness-events shows the "gate-b answered" note at 06:00:50Z and then phase.start implementation at 06:00:51Z with no reviser step; tasks.md stayed at v2, and task 5 then escalated (w-a0050a69) on exactly the defect the annotation named. Cause: src/controller/runs.ts routeRun returns implementation as soon as approvals.tasks.approved, so the Gate B resume block in src/controller/phases/document.ts (around line 691, `dir.kind === 'revise'`) is never reached. "Approve" works only by accident. Fix sketch: in the caller (runs.ts around line 838), before acting on an implementation decision with no task started, look up the run's gate-b wait (gates.pendingGate(run, 'tasks')); if it is answered with a non-approve reply and the approved tasks version still equals the wait's version, run the tasks document phase instead. Add a controller test for both replies.

## Decision Deferred
Route a run back to the tasks document phase when its gate-b wait is answered with an annotation (anything other than empty/"Approve") that has not yet produced a revision, so resumeAfterGateB's reviser round runs.
