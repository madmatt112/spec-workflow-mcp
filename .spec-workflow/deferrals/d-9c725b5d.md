## Context
2026-11-09: dashboard-ruling-view task 7 stopped with "brief: required values 'authorFiles', 'authorReport' missing". isTddMarked (src/controller/phases/implementation.ts:256) tests /\bkind:\s*e2e\b/ over the whole task block, so prompt prose that quotes `kind: e2e` turns a real TDD task into implementer-only and skips the test author. The brief tool (src/tools/harness.ts:751) decides marking with its own rule (any Test line). The quick fix (PR fix/e2e-marked-brief) makes the controller always send empty author keys for a task with tests it routes implementer-only, so the two rules no longer crash the run; it does not fix the false positive. No documented convention exists for the e2e marker: the one real use (tradr) writes it inline in a Purpose line.

## Decision Deferred
Define one rule in core (for example a dedicated `- Kind: e2e` field line, or ignore backtick code spans and the _Prompt/_Leverage lines), use it from both the controller and the brief tool, and document the marker in the tasks drafter rules.
