## Context
In src/core/lint-citations.ts:75 the skip regex is /^\s*_(?:Leverage|Prompt):/, which requires the underscore right after leading whitespace. The tasks template (.spec-workflow/templates/tasks-template.md lines 11-13) mandates the indented sub-bullet form '  - _Prompt:' / '  - _Leverage:', where a '- ' sits between the whitespace and the underscore, so the regex never matches and the identifier check scans prompt/leverage lines. On tdd-task-loop tasks v1 this produced 39 warnings, all to-be-built symbols or JS literals. Fix: widen the regex to /^\s*(?:-\s*)?_(?:Leverage|Prompt):/ (retro F5 intended this class skipped). Alternatives: leave as-is (every tasks spec keeps emitting the noise) or suppress per-token (loses real checks).

## Decision Deferred
The citation-identifier rule fires false positives on every template-compliant tasks.md because the skip pattern misses the standard sub-bullet form.
