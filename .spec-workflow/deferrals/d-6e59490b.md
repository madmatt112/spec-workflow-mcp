## Context
Found during task 13 and confirmed by an independent reviewer, who built a dashboard prompt for a containment-rejection case and read it: the message is absent, because the runner destructures six fields from the prepare response and none carries diff data. The gap is general rather than specific to the rejection — data.diff reaches that prompt for no diff state at all. It was adjudicated a residual, not an in-scope gap: AC 24 is silent where AC 19 explicitly requires the file-resolution counts to reach the agent through both review paths including the dashboard-spawned one; task 13's file list excludes task-review-runner.ts; and task 12's restriction already assigns the structured execution-context payload to worktree-review-signals, whose scope record owns how the diff base, typecheck honesty and attribution reach the agent's prompt. The task is not inert on the dashboard path — the prompt preamble still flips from R4_2A_DIFF_EMPTY to R4_2B, so a rejection is still distinguishable from an empty diff there; only the stated wording does not arrive. Same residual class as the two byte-pinned read-every-file instructions in d-f3cb6fd8.
