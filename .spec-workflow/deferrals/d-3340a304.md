## Context
hasMerged in src/controller/runs.ts reads only the pr.merged ledger row. PR #137 was merged by hand at 2026-11-04T17:56:24Z, so the run had no such row. From 19:52Z the merge stage read #137 again, got mergeable UNKNOWN from GitHub and reported not-ready with the reason "mergeability not yet computed". It polled in this state and flipped between merging and running. Close-out PR #202 stayed open behind it while that polling ran. Run-20261104-034317 ended at 20:23Z, after the operator answered a merge wait for #202.

## Decision Deferred
How the merge stage must detect a PR that is already merged on GitHub. Decide whether it reads the PR state and writes pr.merged itself, for both the run PR and close-out PRs.
