## Context
2026-10-29T15:46Z: sdd-self-update of e12b2499 failed at the eval gate (wait w-6dadd894). drafter-test-seam-label run 1 was marked fail with "edited the live checkout"; runs 2 and 3 passed. At that time run-20261029-104125 (dashboard-project-list) was writing harness-events.jsonl, retrospective-log.md and an implementation log into .spec-workflow/specs/dashboard-project-list/ in the live checkout, which is also swm's spec store. src/evals/runner.ts:89 liveCheckoutChanged returns true when `before.dirty !== after.dirty`, without the isCarvedOut filter it applies to the head diff at line 95. Result: a self-update during any swm run can fail the eval gate. Workaround used: `scripts/sdd-self-update.sh --eval-override drafter-test-seam-label`. Fix: compare the dirty path lists with carved-out paths removed; add a runner test that writes a .spec-workflow file mid-run and expects no fail.

## Decision Deferred
Make liveCheckoutChanged ignore carved-out paths (.spec-workflow/ and the other isCarvedOut paths) in the working-tree dirty comparison, the same way it already ignores them in committed diffs.
