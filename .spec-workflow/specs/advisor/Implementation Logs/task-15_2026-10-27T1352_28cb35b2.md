# Implementation Log: Task 15

**Summary:** Implemented WaitPusher (src/advisor/push.ts): on start, with no pushed.json it records every open wait id without pushing (D3); otherwise it pushes each open wait not yet recorded. It then watches the home waits/ directory (add, change) with chokidar so a wait written by another process is seen. Every file event and the start-up scan run through one shared queue: an open wait not yet recorded is added to pushed.json (pruning ids whose wait file is gone), written, then POSTed with exactly kind/project/spec/dashboardUrl. A failed POST retries once after retryDelayMs, then appends one push.failure event; a missing push.json sends nothing. Wired into src/dashboard/multi-server.ts: the pusher starts only when controller.start() returns true, and stops in server stop().
