### API Endpoints

#### GET /api/controller/actions
- **Purpose:** List every staged advisor action for the dashboard
- **Location:** src/dashboard/multi-server.ts
- **Request Format:** none
- **Response Format:** { actions: StagedAction[] }

#### POST /api/controller/actions/:id/confirm
- **Purpose:** Run a staged action's executor exactly once; operator credential only
- **Location:** src/dashboard/multi-server.ts
- **Request Format:** none
- **Response Format:** { ok: true } or 409 { error: 'not-staged' } or { ok: false, error }

#### POST /api/controller/actions/:id/dismiss
- **Purpose:** Mark a staged action dismissed so it never runs; operator credential only
- **Location:** src/dashboard/multi-server.ts
- **Request Format:** none
- **Response Format:** { ok: true } or 404 or 409 { error: 'not-staged' }

#### Integration
- **Description:** ShellFeed sends a controller-actions message carrying the advisor's staged action list as the sixth message of each flush; HarnessHub re-arms the feed when actions.ts emits actionEvents 'change'

- **Data Flow:** stageAction/confirmAction/dismissAction write -> actionEvents.emit('change') -> HarnessHub.onSourceChange -> ShellFeed.schedule() -> listActions() -> controller-actions message sent to overview subscribers
