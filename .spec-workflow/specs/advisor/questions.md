## Gate A

1. Posture: local only. No money, billing, refunds or credits. Personal data from the job search, notebook and website stays on the machine. The push carries only wait kind, project and spec. Erasure means deleting the home files. No legal framing for a one-operator tool.
   Options: Local-only posture | Send summaries through the push service | Hosted search index
   Answer: Local-only posture

2. The staged-action guard is a separate advisor credential that the confirm route refuses, plus a permission rule that stops the advisor reading the operator secret.
   Options: Scoped advisor credential | Operator secret with a confirm flag | Prompt rule only
   Answer: Scoped advisor credential

3. Meaning search uses a local embedding model whose weights are fetched once at install.
   Options: Local model | Hosted embedding API | Text search only
   Answer: Local model

4. A confirmed staged merge applies the merge rule's checks and refuses on failure.
   Options: Apply merge rule then merge | Merge on confirm with no checks | Merge only through run merge waits
   Answer: Apply merge rule then merge

5. Second-opinion advice becomes typed picks per question plus a short summary. Old text advice still renders.
   Options: Typed picks plus summary | Keep free text | Picks only
   Answer: Typed picks plus summary

6. Proceed with this spec, or do nothing and defer it? Reply "Proceed" to continue, or pick "Do nothing — defer this spec" (optionally followed by a reason) to end the run now — the drafted requirements are kept and no design, tasks or implementation run.
   Options: Proceed | Do nothing — defer this spec
   Answer: Proceed
