## Artifacts

### Functions

#### sdd-launch.sh
- **Purpose:** Launcher body: runs one DeepSeek-provider SDD worker as a claude -p child with its own environment, writes spawn.start and spawn.end (provider=deepseek) through the run event.sh, and prints the worker report on stdout. Refuses (exit 2, one stderr line, no ledger row) when DEEPSEEK_API_KEY is empty, the agent is not a deepseek entry in SDD_PROVIDERS, the agent file is missing, claude is off PATH, or the event script is missing.
- **Location:** harness/skills/sdd-continue/references/sdd-launch.sh
- **Signature:** bash sdd-launch.sh AGENT "MESSAGE"; reads SDD_LAUNCH_BODY, SDD_EVENT_SCRIPT, SDD_SPEC_DIR, SDD_RUN, SDD_SPEC, SDD_CODE_ROOT, SDD_SPEC_STORE_REPO, SDD_HARNESS_REPO, SDD_PROVIDERS from the per-run launch.sh env
- **Exported:** No

### Integrations

#### Integration
- **Description:** The DeepSeek worker child talks to DeepSeek's Anthropic-compatible endpoint (ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic, ANTHROPIC_AUTH_TOKEN=$DEEPSEEK_API_KEY, ANTHROPIC_MODEL/--model=claude-opus-4-8 alias). Reviser worker also loads the spec-workflow MCP server via --mcp-config <code root>/.mcp.json + --allowedTools (frontmatter mcp__ subset); proven by one adversarial-response call answering success:true.
- **Frontend Component:** sdd-launch.sh (launcher body) invoked by the per-run launch.sh
- **Backend Endpoint:** claude -p against api.deepseek.com/anthropic; spec-workflow MCP adversarial-response for the reviser
- **Data Flow:** orchestrator -> bash launch.sh AGENT MESSAGE -> exports SDD_* -> exec sdd-launch.sh -> event.sh spawn.start -> claude -p child (DeepSeek) -> transcript at ~/.claude/projects/<code-root slug>/<session-id>.jsonl -> readUsage sum -> event.sh spawn.end -> child stdout printed as the worker report
