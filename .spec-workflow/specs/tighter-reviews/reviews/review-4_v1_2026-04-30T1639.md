## Findings

### INFO: size-change-at-unchanged-mtime test now asserts preconditions (resolved)
- **File:** src/core/__tests__/adversarial-settings.test.ts:156
- **Issue:** Original test relied on Date round-trip through fs.utimes preserving mtimeMs, which can drift on nanosecond-mtime filesystems. Resolved by (a) rounding mtime to second-precision before the cached read so a later utimes round-trip preserves exact ms, and (b) asserting `stat2.mtimeMs === stat1.mtimeMs` and `stat2.size !== stat1.size` between the writes so the test fails clearly if the (mtime, size) preconditions aren't actually met. Now genuinely proves the size component of the cache key.
- **Task Requirement:** R3.7 size component of cache key

### INFO: vi.mock + vi.mocked.mockImplementationOnce used in lieu of vi.spyOn

Functionally equivalent and required by ESM.
- **Task Requirement:** Task 4 restriction on injection mechanism
