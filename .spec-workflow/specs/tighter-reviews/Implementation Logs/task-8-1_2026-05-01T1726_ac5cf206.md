# Implementation Log: Task 8.1

**Summary:** Added module-level `validateAllFiles(input, projectPath)` and `safeRealpath(path)` helpers in src/tools/review-task.ts per design §validateAllFiles. validateAllFiles wraps every per-element fallible step in try/catch (NUL-byte, Symbol/BigInt/null/undefined-coerced, non-string, path.resolve throws), realpaths BOTH sides of the inside-projectPath check, drops entries whose realpath fails (do NOT fall back to original-path prefix comparison — preserves the symlink-points-outside guarantee), falls back to literal projectPath when safeRealpath(projectPath) returns undefined (asymmetric handling per design Finding #12), and dedupes by realpath form while preserving the first-seen original (resolved) path. safeRealpath wraps realpathSync and silences ENOENT, warns-once for ELOOP/EACCES/ENAMETOOLONG/other I/O errors with the format `[spec-workflow] safeRealpath: <code> on <path>`. Module-private warnOnce uses a `(category:reason)` key so distinct conditions get distinct logs and same-condition repeats are deduped.
