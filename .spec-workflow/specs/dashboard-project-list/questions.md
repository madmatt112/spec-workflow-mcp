1. Where a run's worktree folds into its project
   Options: The dashboard folds the entry when it builds its project set; the registry keeps one entry per worktree | The server registers under the parent project's id | The server skips registration inside a worktree

2. How an eval run stays out of the operator's registry and project list

3. Where and when registrations with a missing path are removed
