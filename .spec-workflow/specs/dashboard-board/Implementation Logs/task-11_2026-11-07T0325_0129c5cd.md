### Integrations

#### Integration
- **Description:** HomePage derives the Needs-you band from board.ts's needsYou(), filters to ControllerWait items (ActionTile arrives in task 12), and renders WaitTile per item; pressing Answer opens AnswerSheet full width in place of the bands, re-derived each render so any answer (here, the route, or elsewhere) returns the board
- **Frontend Component:** HomePage
- **Backend Endpoint:** POST /api/controller/waits/:id/answer (via AnswerSheet's submit)
- **Data Flow:** ShellProvider's controller-waits push -> needsYou(enabled) -> WaitTile list -> Answer press sets openWaitId -> AnswerSheet renders -> submit POSTs the answer -> next controller-waits push drops the wait -> openWait recomputes null -> board returns
