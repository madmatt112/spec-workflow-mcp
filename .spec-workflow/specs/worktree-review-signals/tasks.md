# Tasks Document

Document version: v1

This document sequences the `worktree-review-signals` design into twelve tasks: a per-task record store, git helpers and a base-aware diff, an honest typecheck, new all-drop methodology constants, the two record writers, one `executionContext` built in `handlePrepare`, its rendering in the dashboard runner, the adversarial scaffold's roots, a round-trip-safe encoder, documentation, and the end-to-end scenario. Every task names the design component it delivers and cites the code it edits; the map of that code is `codebase-context.md` beside this file. Checks per task follow `.spec-workflow/agent-rules.md`: `npx tsc --noEmit`, then `npx vitest run` on the test files the task names; the Playwright suite runs only in task 12.

Dependency order: tasks 1 to 5 are independent leaf changes, each leaving the tree compiling and every existing suite green, with task 3 bridging the new `computeTaskDiff` parameter by a `'HEAD'` literal at its one production call. Tasks 6 and 7 (the two writers) need tasks 2 and 3; task 8 (`handlePrepare`) needs tasks 2 to 5 and removes task 3's bridge; task 9 (the runner) needs the types task 8 exports. Tasks 10 and 11 need nothing before them; task 12 runs last and is the only task that runs `npm run test:e2e:worktree`.

## Decisions taken in this document
