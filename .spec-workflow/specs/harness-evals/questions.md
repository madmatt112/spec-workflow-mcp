## Gate A

1. Brief rendered from frozen case values by the build under evaluation
   Options: Frozen values rendered by the build under evaluation | A frozen rendered brief file | Both, chosen per case
   Answer: Frozen values rendered by the build under evaluation

2. A case is selected when its files, role file, profile entry, grader code or rendered brief changed
   Options: Wider set | Role file and template only | Every case on every deploy
   Answer: Wider set

3. Evals run after staged build and smoke, before the live checkout moves
   Options: Before the move | After the move with rollback | After the move, role files left live
   Answer: Before the move

4. Override recorded in a home log plus a deferral carrying the Progress log line
   Options: Home log plus deferral | Deploy appends to Progress log | Deploy commits the line on the live checkout
   Answer: Home log plus deferral

5. Remove the drafter brief template's Test (integration) instruction in this spec
   Options: Fix here | Leave it and override the case | Drop the drafter case
   Answer: Fix here

6. Proceed with this spec, or do nothing and defer it? Reply "Proceed" to continue, or pick "Do nothing — defer this spec" (optionally followed by a reason) to end the run now — the drafted requirements are kept and no design, tasks or implementation run.
   Options: Proceed | Do nothing — defer this spec
   Answer: Proceed
