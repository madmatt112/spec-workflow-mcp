## Gate A

1. A 3-run case keeps its remaining runs after a failed run
   Options: Keep today's behaviour | Stop the case at its first failed run
   Answer: Keep today's behaviour

2. The failure summary states each failing case's run count
   Options: Add the count to the summary | Leave the summary as it is and print the count on stdout only
   Answer: Add the count to the summary

3. A base render failure counts as a brief reason and gives 1 run
   Options: 1 run | 3 runs
   Answer: 1 run

4. Provisional selection states a count for each case and marks the total provisional
   Options: State the count and mark the total provisional | Omit the count for provisional cases | Print a range
   Answer: State the count and mark the total provisional

5. The result record keeps its shape and version
   Options: Keep the shape | Add a planned-runs field | Raise the version
   Answer: Keep the shape

6. Proceed with this spec, or do nothing and defer it? Reply "Proceed" to continue, or pick "Do nothing — defer this spec" (optionally followed by a reason) to end the run now — the drafted requirements are kept and no design, tasks or implementation run.
   Options: Proceed | Do nothing — defer this spec
   Answer: Proceed
