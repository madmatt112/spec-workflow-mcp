## Artifacts

### API Endpoints

#### GET /api/projects/:projectId/harness/setup
- **Purpose:** Return the run-setup view (SetupView) for a project; 404 for an unknown project
- **Location:** src/dashboard/multi-server.ts (registerApiRoutes, harness routes block)
- **Request Format:** none
- **Response Format:** SetupView (see src/dashboard/harness/types.ts)

#### PUT /api/projects/:projectId/harness/setup
- **Purpose:** Validate a SetupInput and write harness-run.json; 404 unknown project, 409 not-launchable, 400 ValidationError, else { file }
- **Location:** src/dashboard/multi-server.ts (registerApiRoutes, harness routes block)
- **Request Format:** SetupInput JSON { spec, supervisorModel, worktree, gates, roles }
- **Response Format:** { file: HarnessRunFile } | ValidationError | { error: 'not-launchable', reason }

#### POST /api/projects/:projectId/harness/launch
- **Purpose:** Force gates:'record', validate, admit, write run file and spawn a detached recorded run; maps every launch outcome incl. the in-flight loser to one status
- **Location:** src/dashboard/multi-server.ts (registerApiRoutes, harness routes block)
- **Request Format:** SetupInput JSON
- **Response Format:** { launch: LaunchRecord } | ValidationError | { error:'not-launchable',reason } | { error:'run-live',runId,reason } | { error,step,detail } | { error }

#### POST /api/projects/:projectId/harness/stop
- **Purpose:** Stop the running/stopping run for a project; 404 not-running when none is live, else { launch }
- **Location:** src/dashboard/multi-server.ts (registerApiRoutes, harness routes block)
- **Request Format:** none
- **Response Format:** { launch: LaunchRecord } | { error: 'not-running' }

### Integrations

#### Integration
- **Description:** The harness routes reuse the task 4 run-setup rule set and the task 5 launcher through the constructor-created HarnessLauncher on the server; admission/writeRunFile/launch run with no await between them so the launcher's synchronous step-1 in-flight guard resolves a concurrent launch race to one 200 and one 409.
- **Frontend Component:** HarnessPage (task C8) fetch/PUT/POST
- **Backend Endpoint:** MultiProjectDashboardServer registerApiRoutes harness routes -> buildSetupView/validateSetup/toRunFile/writeRunFile/readAgentRules (run-setup.ts) and harnessLauncher.admission/launch/get/stop (launcher.ts)
- **Data Flow:** POST launch -> copy body gates:'record' -> buildSetupView -> harnessNotLaunchable/validateSetup -> toRunFile -> admission (sync) -> writeRunFile (sync) -> launch(project,file,worktreeSetup) -> await -> { launch } or LaunchError-mapped status
