**Summary:** Added harness/skills/sdd-continue/references/sdd-run-setup.sh (design C9, D9, D10): the reference script the supervisor runs to turn a saved harness-run.json into supervisor values. Args SPEC_STORE_ROOT ACTIVE_SPEC AGENT_RULES_PATH; run file is SPEC_STORE_ROOT/harness-run.json. No file prints setup=none (exit 0). The node body is a single-quoted string with no apostrophes; the script writes nothing but the deletion and never reads or prints DEEPSEEK_API_KEY. Added one green regression test for single-argument sdd-providers.sh. Synced the three plugins/ copies.
