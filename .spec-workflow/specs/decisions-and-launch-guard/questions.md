## Gate A

1. When round 1 returns only drafting defects, doc review runs one corrective reviser version, lint and narrow check, then approves.
   Options: One corrective reviser version, lint and narrow check, then approve | Approve at once with the findings open | Carry the findings to the next phase
   Answer: One corrective reviser version, lint and narrow check, then approve

2. Next shows one tile per enabled project in a shared store, overriding dashboard-board D11.
   Options: One tile per enabled project | Keep one tile per store with the warning only | Keep one tile and add a project picker
   Answer: One tile per enabled project

3. After a file-list patch the controller re-runs the gate on the same commit.
   Options: Re-gate the existing commit | Spawn a new implementer
   Answer: Re-gate the existing commit

4. A recorded answer that no batch can build becomes a to-do with its reason.
   Options: A to-do with the reason | Infer a landing class from the answer text | Send it to the store batch
   Answer: A to-do with the reason

5. The launch guard warns and never refuses.
   Options: A warning with a second press | Refuse at the server | Hide the tile
   Answer: A warning with a second press

6. Proceed with this spec, or do nothing and defer it? Reply "Proceed" to continue, or pick "Do nothing — defer this spec" (optionally followed by a reason) to end the run now — the drafted requirements are kept and no design, tasks or implementation run.
   Options: Proceed | Do nothing — defer this spec
   Answer: Proceed
