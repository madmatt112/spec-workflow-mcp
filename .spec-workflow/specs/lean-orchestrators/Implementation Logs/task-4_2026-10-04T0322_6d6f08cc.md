# Implementation Log: Task 4

**Summary:** Implemented the `sources` option of the harness `usage` action (design C4). Added `sources: { type: 'boolean' }` to the harness schema and the C4 description sentence (keeping "never spawns a process"). In usageAction, when sources is true, it takes listSpawns, keeps the document and implementation orchestrator spawns, and per spawn resolves the session (resolveSession), locates the transcript (findTranscript), reads it, and breaks it down (breakdownTranscript), building SpawnSources/SourcesReport for both specs onto data.sources and data.compareSources (null without compareSpecName), and passes perUnit to formatUsageTable. Every Error Handling 1 failure reason (no-agent-id, no-session, invalid-id, missing, unreadable, no-usage) becomes an ok:false spawn counted in unknown; the action still succeeds. Added the formatSources block formatter and the SpawnSources/SourcesReport/SourcesReason shapes to src/watch/sources.ts. Without sources the action is byte-identical to before. Updated the usage bullet of docs/TOOLS-REFERENCE.md for the W column, sources and per-unit W.
