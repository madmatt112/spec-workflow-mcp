# Implementation Log: Task 10

**Summary:** Added the `book-script` brief kind (design C6 row, C7) that renders `book.sh`, an idempotent, segment-driven bookkeeping script. It is run as `bash book.sh <segment> [-- <segment>]...` with segments event, check, retro, state, commit, head, changes, edit — each with the C7 effect and already-landed rule. It reads SDD_RUN/SDD_LEDGER from EVENT_SCRIPT and SDD_RETRO_LOG from retroScript (parsed with grep|cut), appends ledger rows only by calling EVENT_SCRIPT, runs under set -u, exits 1 naming the failed segment (no later segment runs) and exit 2 on a usage/unknown segment. Written with String.raw so embedded node regexes keep backslashes; the four seg-array expansions and the fenced-diff backticks are the only interpolations. Registered in BRIEF_TEMPLATES (mode write) with required caller keys eventScript, retroScript, specDir, specStoreRepo, codeRoot, handoff (spec is server-filled). Updated the TOOLS-REFERENCE brief bullet for the kinds tasks 8-10 add, append mode and book-script.
