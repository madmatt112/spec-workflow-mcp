# Implementation Log: Task 2

**Summary:** Implemented design C2 as a new pure module src/watch/sources.ts exporting breakdownTranscript(text). It groups a subagent transcript's assistant lines into calls by message.id (last usage wins, a no-id line is its own call), snapshots each call's preceding context blocks, labels each block by source per the C2 table, splits each call's input W between base and the context sources by character size, and charges 5*output_tokens to own-output. base is sized once from the first call's residual (max(0, ctx1 - C1/3.5)); when a call has zero preceding chars or zero ctx, its whole inW goes to base. Returns null when no assistant line carries message.usage. Outputs calls, peak (max ctx), base (total base W), w (sum inW+5*output) and rows (sources with W>0, each with its share, sorted W-descending). All 14 author tests pass; tsc clean.
