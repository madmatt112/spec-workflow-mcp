### Functions

#### hasNoReviewableFiles
- **Purpose:** Decides the all-drop disclosure case (R4 AC 20) from the three published counts ALONE, so the runner needs no fourth field: true iff workspaceCount === 0 AND (workflowCount > 0 || sum(drops) > 0). That disjunction is exactly 'the log listed at least one file' — every logged entry either resolves (into workspaceCount or workflowCount) or increments a drop, and the realpath dedupe only ever collapses entries that resolved. An empty implementation log yields zeros throughout and is deliberately NOT a disclosure case. Note workflowCount > 0 with workspaceCount === 0 IS a disclosure case: a .spec-workflow document is readable but is not the implementation.
