#### resolveLoggedFiles
- **Purpose:** Resolves raw implementation-log file entries against two roots. REPLACES validateAllFiles (deleted). Relative entries are anchored workspace-first then workflow-root-second; absolute entries are NOT anchored (path.resolve ignores its base for them) and are classified by containment alone. Containment accepts the workspace or <workflowRoot>/.spec-workflow, both realpath-normalized, never the workflow root itself (a nested layout puts every sibling worktree under it). The workflow-root candidate is accepted only when it lands inside .spec-workflow — that single rule reconciles 'anchor the workflow root second' (R4 AC 8) with 'drop, never substitute' (R4 AC 14): a code file missing from the workspace but present in the main checkout fails the .spec-workflow test and is dropped as `missing`, silently. Results are deduped by realpath and preserve first-seen order. Ambiguity is set only for relative entries whose two anchors resolve to two DISTINCT existing files, so equal roots (the single-checkout population) never produce it.
- **Location:** src/core/file-resolution.ts:151
- **Signature:** resolveLoggedFiles(input: unknown, roots: { workspacePath: string; workflowRoot: string }): FileResolution
