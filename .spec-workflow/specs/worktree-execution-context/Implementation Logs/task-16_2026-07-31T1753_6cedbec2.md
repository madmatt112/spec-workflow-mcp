### Functions

#### resetSpecWorkflowHome
- **Purpose:** REPLACES the `rm -rf $SPEC_WORKFLOW_HOME; mkdir` idiom both worktree suites used in beforeAll. Truncates activeProjects.json to `{}` and never removes the directory. THE BUG IT FIXES, found by running both suites in one process: the dashboard watches activeProjects.json with chokidar, and while that file does not exist the watch lives on its PARENT DIRECTORY. Deleting the directory destroys the watch permanently, so the dashboard never observes another registration and every LATER suite in the same run times out waiting for projects that demonstrably did register (the child logged 'Project registered'). Any future e2e suite sharing one dashboard must use this, not rm -rf.
