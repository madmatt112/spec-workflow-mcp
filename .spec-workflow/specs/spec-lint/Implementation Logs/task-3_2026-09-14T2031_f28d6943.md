**Summary:** Created src/core/lint-citations.ts (design Component 4, requirements 1.9, 2.1-2.7, NFR Security). Exports CITATION_RE (path:line / path:a-b, rejects ports/versions/URLs, allows a leading / so it can be flagged), BARE_RANGE_RE, the Citation type, extractCitations (scans unfenced lines incl. inline code; a bare backticked range borrows its block's nearest earlier path citation, else path=''), identifierTokens (2.6 filters: strip trailing (...), drop paths/citations/file-names, keep the last dot-segment matching the id regex), and async checkCitations(lines, bases). checkCitations resolves each distinct path once via PathUtils.safeJoin over the bases in order (a '..'/absolute path is citation-path error, never read), first existing base wins; a directory/unreadable/non-UTF-8 (isUtf8) file is citation-unchecked info; out-of-range (0, A>B, past EOF) is citation-range error; citation-bare info for an unresolvable bare; and citation-identifier warning on the block's first line for identifiers absent from the joined in-range cited text (D4: only blocks with a resolved citation). NOTE doc-gap: the design prose lists /etc/hosts:1 as a CITATION_RE match, but that literal requires a .ext, so /etc/hosts (no extension) does not match; tested the leading-/ citation-path case with an extension-bearing absolute path.
